# Carbon Khata

Carbon Khata carries a steel mill's verified emissions, lot by lot through stockists, into a verifier-signed EU CBAM file for Indian MSME exporters.

This site walks through each user of the ledger: the exporter, the stockist, the steel mill, the verifier, the EU importer, the lender and the EEPC cluster cell. It also has a CBAM calculator.

Built by Team Carbon Khata (XLRI Delhi-NCR) for the Quest EYP 2026 final.

Firms, lots, invoice numbers and heat numbers are demo data. Regulatory values and prices are real: EU Reg. 2023/956; IR 2025/2546, 2025/2547, 2025/2620, 2025/2621 as amended by 2026/1740; Reg. (EU) 2026/1384; DG TAXUD quarterly certificate prices (€75.28 in Q2 2026); €1 = ₹108.

Static site, no build step. Open `index.html` or deploy the folder as is.
